# The System I'd Build (episode writer)

Bright Matter's answer to the "content ideas for [industry]" reel format: the content plan **and** the system that shows leadership it worked. Strategy lives in `Bright-Matter-HQ/brand/BRAND_STRATEGY.md`; the series spec and episode bank are in `Bright-Matter-HQ/brand/ADS_AND_CONTENT.md` §3. Read both first.

## Steps

1. **Pick the business** (from the episode bank or Shannon's ask). Confirm it has multiple locations; the series is only for multi-location businesses.
2. **Find the real customer objection** for that industry. If unsure, run a quick search for common complaints in reviews of that category; cite what you used.
3. **Write the episode** in the fixed six-beat format: hook (0:00 to 0:04), proof (0:04 to 0:10), #1 People, #2 Series, #3 The System, close with "Comment AUDIT". Keep under 80 seconds spoken.
4. **#3 must name one concrete alert** a leader would act on that week (for example a review drop at one location, a post spiking, a complaint keyword).
5. **Deliver:** the script table (time, visual, spoken), on-screen text, a LinkedIn caption (first line is the hook), a Reels/TikTok caption, and a 45-second paid cut.

## Proof rules

1. Greenway numbers only at the permission level Shannon has confirmed (`BRAND_STRATEGY.md` §6). Default is Level 1: no client name, no client numbers, no client faces or footage.
2. Visuals of reporting use sample data only.
3. No invented statistics about the industry; if a figure is used, name its source.
4. No em dashes. Plain, specific, first person.
